Улики,
которые молчат.

Пять предметов с места обнаружения. Нажмите на карточку, чтобы отделить физический объект от смысла, который ему приписали позже.

Каталог / 05 позиций

Вещество
против легенды.

Каждая улика здесь отрисована как схема, а не как реконструкция внешности. Мы знаем, что предмет был найден. Не всегда знаем — зачем он был нужен. Открывайте карточки, чтобы увидеть границу между этими двумя фразами.

01 / OBJECT

Свинцовые маски

Две самодельные накладки, закрывавшие область глаз. Самый сильный образ дела — и его самая немая улика.

02 / OBJECT

Бутылка воды

Обычный предмет, который делает маршрут конкретным: на холме люди рассчитывали провести время.

03 / OBJECT

Записка

Список времени, капсула, защита и сигнал. Несколько строк, породивших десятилетия догадок.

04 / OBJECT

Плащи

Одинаково практичная и зловещая деталь: одежда от дождя в день без известной непогоды.

05 / OBJECT
20:30?

Время

Часы и отметки в записке не совпадают в одну простую картину. Самая важная улика — промежуток.

Инвентарная заметка

Предметы не обязаны иметь один смысл.

Вода может быть водой. Плащ — плащом. Свинцовая маска — не обязательно ключом к другой цивилизации. Улика становится версией только после интерпретации.
